# Widget Notification

## 📖 Description

The **Widget Notification** is a reusable component designed for displaying notifications in your application. It is easy to integrate into any project, providing a simple and efficient way to alert users about important events.

## 🚀 Features

- **Customizable Design**: Easily adapt the widget to fit your application's style.
- **Responsive**: Works seamlessly across devices and screen sizes.
- **Ease of Integration**: Add to your project with minimal setup.
- **Efficient Notification Management**: Notify users about events dynamically.
